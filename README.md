# Deploy PSD Kelas B

Repository ini merupakan kumpulan proyek deployment untuk mata kuliah Pengolahan Sinyal Digital (PSD) Kelas B. Repository ini mengorganisasi proyek-proyek kelompok ke dalam tiga kategori klasifikasi:

- **Klasifikasi Alas Kaki** - Proyek klasifikasi berbasis citra alas kaki.
- **Klasifikasi Geografis** - Proyek klasifikasi berbasis data geografis.
- **Klasifikasi Suara** - Proyek klasifikasi berbasis sinyal audio, mencakup beberapa sub-proyek kelompok (K1–K7) seperti klasifikasi suara umum, deteksi suara kran air, klasifikasi sawmill, klasifikasi audio, deteksi tangisan, dan deteksi kebocoran gas.

Masing-masing sub-proyek dikelola sebagai Git submodule yang merujuk ke repository kelompok terkait.
